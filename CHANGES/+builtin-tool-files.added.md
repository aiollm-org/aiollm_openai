Files of the code interpreter: `response.files` (and `CompletedEvent.files`) lists the files of a container that the answer cites (`container_file_citation`), once each, as `ProducedFile`s with their `filename` and `container_id`; `client.files.download(file)` streams one from its container with the new method `RetrieveContainerFileContent` (`GET /containers/{container_id}/files/{file_id}/content`). OpenAI names a file only when the text refers to it. `CodeExecution(files=[...])` sends stored files as the automatic container's `file_ids`.
